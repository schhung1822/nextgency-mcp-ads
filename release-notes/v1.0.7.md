Ads MCP by noti.vn - phiên bản 1.0.7

Bản cập nhật nhỏ: thêm cách cài đặt trên VPS bằng một lệnh và lệnh tiện ích ads-mcp. Phần mềm (web, MCP, dữ liệu) không thay đổi so với 1.0.6 - máy chủ đang chạy không cần làm gì thêm ngoài bấm Cập nhật như mọi lần.

CÀI ĐẶT BẰNG MỘT LỆNH - MỚI

- Trên VPS mới (Ubuntu 22.04/24.04 hoặc Debian 12/13), chạy:
  curl -fsSL https://raw.githubusercontent.com/notivn/ads-mcp-simple-install/main/install-ads-mcp.sh -o install-ads-mcp.sh
  sudo bash install-ads-mcp.sh
- Script hỏi tên miền, email, tài khoản GitHub và token GitHub (nhập ẩn), rồi tự: kiểm tra token và tên miền, tạo swap khi RAM ít, bật tường lửa, cài Docker, tải bản phát hành mới nhất, tạo cấu hình với khoá bí mật ngẫu nhiên, bật HTTPS và cập nhật tự động. Cuối cùng hiện link /setup và mã cài đặt để tạo tài khoản quản trị.
- Chỉ cần 1 token GitHub (classic) có quyền repo và read:packages - dùng chung cho tải phần mềm, tải image và kiểm tra bản mới. Máy đã cài theo cách cũ (2 token) vẫn chạy bình thường, không cần đổi.
- Hướng dẫn: README của https://github.com/notivn/ads-mcp-simple-install và docs/deploy-vps.md mục 0.

LỆNH TIỆN ÍCH ads-mcp - MỚI (máy cài bằng script)

- sudo ads-mcp status / doctor (tự chẩn đoán lỗi thường gặp) / logs / setup-key / token (đổi token GitHub) / update / update-config / backup.

CÁCH CẬP NHẬT

- Quản trị viên vào Cài đặt → Cập nhật hệ thống → bấm Cập nhật lên v1.0.7.
- Hoặc chạy tay trên máy chủ, trong thư mục cài đặt: docker compose pull && docker compose up -d
- Không đổi docker-compose.yml (chỉ sửa dòng chú thích), Caddyfile, deploy/ hay biến môi trường.
- Image: ghcr.io/notivn/ads-mcp-simple:1.0.7 và ghcr.io/notivn/ads-mcp-simple-updater:1.0.7.
