Ads MCP by noti.vn - phiên bản 1.0.0

Bản phát hành đầu tiên. Kết nối tài khoản quảng cáo Meta và OpenAI Ads, rồi điều khiển quảng cáo bằng ngôn ngữ tự nhiên từ Claude, ChatGPT hoặc Gemini qua MCP (mỗi MCP có một link riêng dạng https://tên-miền-của-bạn/mcp/…).

KẾT NỐI QUẢNG CÁO

- Meta (Facebook/Instagram): dán token cá nhân của via (Graph API Explorer) hoặc System User token. Token ngắn hạn tự đổi sang token ~60 ngày khi có App ID + App Secret. Một token thấy mọi tài khoản quảng cáo và Trang mà via được phân quyền, kể cả trong Business Manager.
- OpenAI Ads: dán API key của tài khoản quảng cáo.
- Kiểm tra token trước khi lưu, chọn tài khoản được dùng, cảnh báo token sắp hết hạn, đồng bộ tài khoản mới mỗi ngày (tài khoản mới luôn ở trạng thái tắt cho tới khi bạn bật).
- Google Ads và TikTok Ads: sắp ra mắt trong các phiên bản tới.

MCP CHO CLAUDE / CHATGPT / GEMINI

- Mỗi MCP có link riêng, chọn nền tảng, tài khoản quảng cáo, Trang Facebook và quyền (Xem, Bật/Tắt, Sửa, Sao chép, Tạo mới, Xoá).
- Báo cáo chỉ số theo ngày hoặc tổng: mặc định kéo MỌI chỉ số có trên nền tảng (chi tiêu, hiển thị, reach, click, CTR, CPC, CPM, chuyển đổi, giá trị chuyển đổi, CPA, ROAS, mua hàng, khách tiềm năng, tin nhắn, video... kèm chỉ số riêng của nền tảng như add_to_cart, landing_page_view, video_p75). Hỏi chỉ số cụ thể thì chỉ trả đúng các chỉ số đó. Tiền theo đơn vị chính của từng tiền tệ, không cộng chéo tiền tệ; ngày theo múi giờ tài khoản.
- Xem chiến dịch, nhóm quảng cáo, quảng cáo; bật/tắt; sửa ngân sách, giá thầu, lịch; sao chép; xoá/lưu trữ; tải ảnh/video từ URL; tra cứu Trang, pixel, vị trí, sở thích, tệp đối tượng.
- Meta: tạo chiến dịch, nhóm quảng cáo, quảng cáo (luôn ở trạng thái tạm dừng), sửa nhắm mục tiêu.
- OpenAI Ads: tạo chiến dịch, nhóm quảng cáo, quảng cáo, sửa nhóm quảng cáo, xem chuyển đổi.
- Trang Facebook (chỉ đọc): danh sách Trang, bài viết (đã đăng, bài khách đăng, bài quảng cáo, bài hẹn giờ), chi tiết bài, chỉ số bài và chỉ số Trang theo ngày/tuần/28 ngày.

AN TOÀN

- Thao tác ghi có xác nhận 2 bước (AI phải cho bạn xem trước), trần ngân sách/giá thầu theo từng tiền tệ, giới hạn % đổi ngân sách, giới hạn số lệnh, danh sách IP được phép, ngày hết hạn của MCP.
- Đối tượng tạo mới hoặc sao chép luôn ở trạng thái tạm dừng.
- Token và key MCP được mã hoá (AES-256-GCM), không bao giờ hiển thị lại hay gửi cho AI.
- Phân quyền Quản trị viên / Nhân viên: nhân viên chỉ thấy và dùng kết nối, MCP của chính mình.
- Đăng nhập có 2FA (TOTP), khoá khi nhập sai nhiều lần, xác thực lại trước thao tác nhạy cảm.

NHẬT KÝ & THEO DÕI

- Nhật ký từng lệnh MCP (ai, AI nào, tool, tài khoản, kết quả, trước/sau khi sửa) và nhật ký thao tác của nhân sự, lưu theo số tháng cấu hình, xuất CSV.
- Trang Tổng quan: lượt gọi theo nền tảng, cảnh báo token, MCP đang hoạt động.

CẬP NHẬT 1 CHẠM

- Quản trị viên bấm Cập nhật trong Cài đặt → Cập nhật hệ thống: hệ thống tự sao lưu dữ liệu, tải bản mới, cập nhật cơ sở dữ liệu, khởi động lại và tự quay về bản cũ nếu bản mới lỗi.
- Khi cập nhật lỗi, thông báo nêu rõ nguyên nhân và cách xử lý (ví dụ GHCR từ chối quyền tải image kèm thư mục thông tin đăng nhập mà updater đang dùng).

CÀI ĐẶT

- Chạy bằng Docker Compose trên VPS (Ubuntu 24.04 / Debian 12-13, amd64 hoặc arm64), HTTPS tự động bằng Caddy, hoặc sau Cloudflare / Nginx / Cloudflare Tunnel.
- Hướng dẫn: docs/deploy-vps.md. Image: ghcr.io/notivn/ads-mcp-simple:1.0.0 và ghcr.io/notivn/ads-mcp-simple-updater:1.0.0.
