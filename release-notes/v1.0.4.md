Ads MCP by noti.vn - phiên bản 1.0.4

Bản cập nhật nhỏ: thêm nút báo lỗi / yêu cầu tính năng, hiển thị phiên bản ngay trên thanh bên và tự kiểm tra bản mới khi mở trang Cập nhật hệ thống. Không thay đổi cơ sở dữ liệu, không ảnh hưởng kết nối quảng cáo, MCP và nhật ký đang dùng.

BÁO BUG, YÊU CẦU TÍNH NĂNG (MỚI)

- Nút "Báo bug, yêu cầu tính năng" luôn nằm ở góc dưới bên phải mọi trang quản trị. Bấm vào để mở form gửi trực tiếp cho noti.vn (tab mới).
- Trên máy tính hiện icon kèm chữ; trên điện thoại chỉ hiện icon cho gọn, nằm ngay trên thanh điều hướng dưới.
- Nút tự nâng lên khi trang có thanh nút ở đáy (ví dụ các bước thêm kết nối) và tự ẩn khi bàn phím điện thoại đang mở.

PHIÊN BẢN TRÊN THANH BÊN

- Ngay trên tên tài khoản ở thanh bên (máy tính) có ô "Phiên bản": phiên bản đang chạy và - với quản trị viên - phiên bản mới nhất, kèm nhãn "Có bản mới" hoặc "Đã cập nhật".
- Quản trị viên bấm vào ô này để mở Cài đặt → Cập nhật hệ thống, đọc ghi chú phát hành và quyết định có cập nhật hay không. Nhân viên chỉ thấy số phiên bản đang chạy.

TỰ KIỂM TRA BẢN MỚI

- Mở Cài đặt → Cập nhật hệ thống là hệ thống tự hỏi GitHub ngay và hiện kết quả, không cần bấm "Kiểm tra ngay". Nút "Kiểm tra ngay" vẫn còn để kiểm tra lại.
- Nếu máy chủ chưa đặt UPDATE_GITHUB_TOKEN (kho mã riêng tư), trang hiện lý do không kiểm tra được như trước.

CÁCH CẬP NHẬT

- Quản trị viên vào Cài đặt → Cập nhật hệ thống → bấm Cập nhật lên v1.0.4 (hệ thống tự sao lưu và tự quay về bản cũ nếu lỗi).
- Hoặc chạy tay trên máy chủ, trong thư mục cài đặt: docker compose pull && docker compose up -d
- Bản này không đổi docker-compose.yml, Caddyfile, deploy/ hay .env.example - không cần git pull trên máy chủ.
- Image: ghcr.io/notivn/ads-mcp-simple:1.0.4 và ghcr.io/notivn/ads-mcp-simple-updater:1.0.4.
