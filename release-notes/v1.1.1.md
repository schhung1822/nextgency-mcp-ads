Ads MCP by noti.vn - phiên bản 1.1.1

Apify trở thành một nền tảng ngang hàng với Meta, TikTok, Google Ads và OpenAI Ads khi tạo / sửa MCP: một MCP vừa đọc số liệu, tạo, sửa, bật/tắt quảng cáo, vừa lấy dữ liệu qua Apify để phân tích. Không đổi cấu hình máy chủ, chỉ cần bấm Cập nhật.

APIFY LÀ MỘT NỀN TẢNG CỦA MCP

- Bước "Nền tảng & tài khoản" có thêm thẻ Apify (cùng hàng với Meta, TikTok, Google Ads, OpenAI Ads): bật "Dùng Apify trong MCP này", xem kho token đang dùng được (token công ty + token cá nhân của chủ MCP). Chưa có token thì có nút "Thêm token Apify".
- Bước "Quyền" có thẻ Apify riêng (cùng kiểu với các nền tảng khác): trần mỗi lần chạy (USD) và công tắc "Cho phép Actor ngoài danh mục" (chỉ quản trị viên). Bỏ mục "Lấy dữ liệu (không bắt buộc)" cũ.
- Tạo được MCP chỉ dùng Apify (chuyên nghiên cứu thị trường) - chỉ cần có ít nhất 1 token Apify dùng được; hoặc MCP kết hợp quảng cáo + Apify.
- Tab Tổng quan của MCP hiện khối Apify trong "Phạm vi MCP"; danh sách MCP có biểu tượng Apify và bộ lọc theo Apify.

CÁCH CẬP NHẬT

- Quản trị viên vào Cài đặt → Cập nhật hệ thống → bấm Cập nhật lên v1.1.1.
- Hoặc chạy tay trên máy chủ, trong thư mục cài đặt: docker compose pull && docker compose up -d
- Không đổi docker-compose.yml, Caddyfile, deploy/ hay biến môi trường. Không có thay đổi cơ sở dữ liệu.
- Image: ghcr.io/notivn/ads-mcp-simple:1.1.1 và ghcr.io/notivn/ads-mcp-simple-updater:1.1.1.
